# /gl-spec — สร้าง Specification สำหรับ Grace Ledger

สร้าง specification สำหรับ feature ใหม่ใน Grace Ledger โดยทำตามขั้นตอน:

1. **ถามว่าจะสร้างอะไร** — ใช้คำถามเหล่านี้:
   - "ฟีเจอร์นี้แก้ปัญหาอะไร?"
   - "ใครใช้? (ผู้ใช้/แอดมิน/บัญชี)"
   - "มีการเงินเกี่ยวข้องไหม? (รายรับ/รายจ่าย/กองทุน)"
   - "ต้องเชื่อมกับ Supabase RPC ไหม?"

2. **ตรวจสอบก่อนเขียน:**
   - อ่าน `CLAUDE.md` ส่วน "Financial safety — hard stops"
   - อ่าน `design-system-extracted/tokens/` ว่ามี token ไหนใช้ได้
   - ตรวจว่ามี component ที่ใช้ซ้ำได้ใน `src/components/` ไหม

3. **เขียน spec ในรูปแบบ:**
   ```markdown
   ## [ชื่อ Feature]
   
   **ปัญหา:** [อธิบายปัญหา 1 บรรทัด]
   **ผู้ใช้:** [ใครใช้]
   **การเงิน:** [มี/ไม่มี — ถ้ามีระบุประเภท]
   
   **ขอบเขต:**
   - [ ] สิ่งที่ทำ
   - [ ] สิ่งที่ไม่ทำ
   
   **Technical:**
   - RPC: [ชื่อ RPC ถ้ามี]
   - Components: [components ที่ต้องสร้าง/แก้]
   - Tests: [test cases ที่ต้องมี]
   ```

4. **ยืนยันกับผู้ใช้** — ถามว่า "ถูกต้องไหม? มีอะไรต้องเพิ่ม/ลบไหม?"

**ห้าม:**
- ❌ เขียนโค้ดก่อนได้รับการยืนยัน
- ❌ สร้าง design token ใหม่ถ้ามีอยู่แล้ว
- ❌ ใช้ `number` สำหรับเงิน — ใช้ `decimal.js` เสมอ
