5 · Navigation Principles

Sidebar 240px + Topbar 56px · เนื้อหา ≤1200px
เมนู 5 กลุ่ม: ภาพรวม / การเงิน / การควบคุม / จัดการ / ระบบ
ทุกหน้า ≤ 2 คลิก · ปุ่ม primary เดียวต่อหน้า มุมขวาบน
ของค้างแสดง badge บนเมนู · role เห็นตลอดที่ topbar
role อ่านอย่างเดียว → แถบเหลืองแจ้งใต้ topbar

6 · Responsive Rules

KPI: auto-fit minmax(210px,1fr)
2 คอลัมน์: flex-wrap (2 1 420px / 1 1 280px)
ตาราง: overflow-x auto + min-width 820px — ห้ามคอลัมน์ทับกัน
ข้อความยาว: nowrap + ellipsis · touch target ≥ 44px

7 · Accessibility

Contrast ≥ 4.5:1 · ห้ามจางกว่า #9AA0B4 บนพื้นขาว
Focus ring 2px primary ทุก input/ปุ่ม
สถานะ = สี + จุด + ข้อความ ไม่พึ่งสีอย่างเดียว
ตัวอักษร ≥ 11px · prefers-reduced-motion เสมอ

8–10 · Empty · Error · Loading States

ไม่มีรายการค้างอนุมัติ
ทุกรายการได้รับการตรวจสอบแล้ว
EMPTY — icon tile 48 + หัวข้อ + คำอธิบาย + การกระทำถัดไป
กรุณาระบุจำนวนเงินให้ถูกต้อง — ต้องมากกว่า 0 บาท
เครือข่ายขัดข้อง → การ์ด + ปุ่มลองใหม่
ERROR — บอกวิธีแก้ ไม่ใช่แค่ "ผิดพลาด" · คงค่าที่กรอกไว้
LOADING — skeleton ตรงรูปทรงเนื้อหา ห้าม spinner กลางจอ

12 · Form Standard

ฟอร์มอยู่ใน drawer 420px — ไม่เปลี่ยนหน้า
จำนวนเงิน = ฟิลด์แรก ใหญ่สุด (Inter 20/600)
แนบหลักฐานมีเสมอ (AI อ่านใบเสร็จ)
Submit = "บันทึกและส่งขออนุมัติ" → pending เสมอ
Error ใต้ฟอร์ม + คงค่าที่กรอก

13 · Dashboard Standard

ลำดับ: เงินสดรวม (การ์ดเข้ม) → รายรับ/จ่ายเดือนนี้ → ถวายล่าสุด → กองทุน → รายการล่าสุด → คอลัมน์ขวา (อนุมัติ/งบ/AI)
KPI = kicker + ตัวเลข Inter + บริบท 1 บรรทัด
Quick actions เฉพาะ role ที่มีสิทธิ์

14 · AI Workspace Standard

การ์ด AI = gradient indigo + ขอบ #C7D2FE แยกจากข้อมูลจริง
ทุก insight: เหตุผล + chip หลักฐาน + chip ความมั่นใจ
guardrail: "AI ให้ข้อสังเกตเท่านั้น — ไม่แก้ไข/อนุมัติ"
AI ไม่มีปุ่มแก้ข้อมูลการเงิน — ลิงก์ไปดูหลักฐานเท่านั้น
หลักฐาน: 6 รายการ ความมั่นใจ 86%
