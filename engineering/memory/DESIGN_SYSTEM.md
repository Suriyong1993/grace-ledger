# Shared Project Brain — Design System Specification

## Color Palette (Warm Ivory & Gold Amber)
- `--color-primary`: Gold Amber (`oklch(0.65 0.16 70)`)
- `--color-background`: Warm Ivory (`oklch(0.98 0.01 80)`)
- `--color-card`: Pure Card White (`oklch(1 0 0)`)
- `--color-success`: Mint Emerald (`oklch(0.62 0.17 155)`)
- `--color-destructive`: Crimson Red (`oklch(0.55 0.22 25)`)

## Typography
- **Headings**: `Prompt`, `Kanit`, sans-serif (Font Display)
- **Financial Numbers**: Monospace / tabular numbers (`num-display`)

## Utilities
- `card-ledger`: Editorial financial card container with border and subtle shadow.
- `kicker`: Small uppercase tracking text for metric labels.
