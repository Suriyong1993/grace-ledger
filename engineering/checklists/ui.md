# Quality Checklist: UI/UX & Aesthetics

- [ ] Does the UI strictly use Warm Ivory & Gold Amber OKLCH design tokens?
- [ ] Is typography hierarchy clear, using Prompt/Kanit font display headers?
- [ ] Are financial numbers rendered in tabular/monospace formatting (`num-display`)?
- [ ] Is there zero generic "AI Slop" (e.g. basic plain borders, unstyled cards)?
- [ ] Does the layout adapt gracefully from mobile phones to high-resolution desktop displays?
