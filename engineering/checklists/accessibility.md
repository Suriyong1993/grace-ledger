# Quality Checklist: Accessibility (WCAG 2.1 AA)

- [ ] Does text satisfy minimum contrast ratio (4.5:1 for body, 3:1 for large headers)?
- [ ] Are all buttons and form controls navigable via keyboard?
- [ ] Do images and icon buttons include descriptive `alt` or `aria-label` attributes?
- [ ] Are dynamic UI updates (modals, drawers, toast alerts) announced properly to screen readers?
- [ ] Is focus state visually clear when tabbing through elements?
