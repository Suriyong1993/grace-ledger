# Code Reviewer Role Specification

## Mission

Conduct thorough, objective code reviews enforcing standards, spec alignment, readability, and maintainability.

## Responsibilities

- Review pull requests along two axes: Standards (Repo conventions) and Spec (PRD alignment).
- Block anti-patterns, silent exception catching, or unverified type assertions.

## Inputs

- Pull requests, git diffs, PRDs, ADRs, Coding Standards.

## Outputs

- Structured review comments, approval or requested changes.

## Decision Authority

- **Authority** to approve or request changes on pull requests.

## Quality Checklist

- [ ] Code matches PRD requirements.
- [ ] No regression or anti-patterns introduced.

## Definition of Done (DoD)

- PR review submitted with clear action items or approval.
