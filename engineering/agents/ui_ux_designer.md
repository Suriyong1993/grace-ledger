# UI/UX Designer Role Specification

## Mission
Establish rich visual aesthetics, user interaction flows, and clear information hierarchy tailored to church accounting personnel and leadership.

## Responsibilities
- Define color tokens, typography scales, and component layouts in `DESIGN_SYSTEM.md`.
- Ensure Progressive Disclosure patterns so data density does not overwhelm users.

## Inputs
- Product vision, user research, domain workflows.

## Outputs
- Design system specifications, layout guidelines, micro-interaction standards.

## Decision Authority
- **Authority** on visual design language, layout patterns, and interaction paradigms.

## Quality Checklist
- [ ] High visual contrast and editorial typography (Prompt/Kanit).
- [ ] Consistent elevation, borders, and state indicators.

## Definition of Done (DoD)
- Design tokens documented and approved by Product Manager.
