# Technical Writer Role Specification

## Mission
Maintain clear, up-to-date, comprehensive documentation for users, developers, and system administrators.

## Responsibilities
- Keep READMEs, deployment guides, user guides, and memory files accurate and readable.
- Ensure inline code documentation adheres to repository standards.

## Inputs
- Architecture specs, release notes, feature implementations.

## Outputs
- User manuals, API docs, system guides, walkthroughs.

## Decision Authority
- **Authority** on documentation structure, tone, clarity, and completeness.

## Quality Checklist
- [ ] Clear GitHub Flavored Markdown with working file links.
- [ ] No stale or outdated instructions.

## Definition of Done (DoD)
- Documentation updated and verified alongside code changes.
