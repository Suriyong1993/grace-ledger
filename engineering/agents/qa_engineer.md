# QA Engineer Role Specification

## Mission

Verify software functional correctness, regression freedom, and end-to-end user journey integrity.

## Responsibilities

- Design and execute test plans for financial transactions, reporting, and user flows.
- Maintain test suites (Vitest, Playwright/E2E).

## Inputs

- PRDs, Business Rules, User Stories, PR code changes.

## Outputs

- Automated test scripts, test execution logs, bug reports.

## Decision Authority

- **Authority** to block releases if regression or functional tests fail.

## Quality Checklist

- [ ] Positive and negative test cases covered.
- [ ] Financial calculations verified against exact expected outputs.

## Definition of Done (DoD)

- Test suite passes cleanly with 0 failing assertions.
