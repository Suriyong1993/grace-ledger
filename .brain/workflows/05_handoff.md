# Workflow 05: Handoff (การส่งมอบงานและการจดจำสถานะ)

> **เป้าหมาย:** ส่งมอบงานให้ Agent ถัดไป (หรือมนุษย์) ได้อย่างราบรื่น โดยไม่ต้องเริ่มอธิบายบริบทใหม่

---

## ขั้นตอนปฏิบัติเมื่อสิ้นสุดงาน (Handoff Protocol)

1. **อัปเดต Working Context**:
   - เปิด `.brain/WORKING_CONTEXT.md`
   - ทำเครื่องหมาย `[x]` ในงานที่ทำเสร็จแล้ว
   - ระบุ Active Task ใหม่ หรือปรับสถานะเป็น `IDLE` / `WAITING_FOR_REVIEW`
   - ใส่รายชื่อไฟล์ที่ถูกแก้ไขในรอบนี้
   - อัปเดตสถานะการทดสอบล่าสุด (Test / Build baseline)

2. **บันทึกหลักฐานลงใน Handoff Log**:
   - เปิด `.brain/HANDOFF.md`
   - เพิ่มบล็อกบันทึกใหม่ที่ **ด้านบนสุดของไฟล์** ตาม Template ที่กำหนด
   - ระบุ:
     - ผู้ส่งมอบ (เช่น Claude Code, Gemini, Codex)
     - บริบทงานและสิ่งที่ทำเสร็จ
     - ไฟล์ที่แก้ไข
     - หลักฐานการทดสอบ (`npm test`, `npm run build`)
     - ขั้นตอนที่ต้องทำต่อ (Next Steps) สำหรับ AI ตัวต่อไป
     - ข้อควรระวัง (Gotchas)

3. **บันทึกบทเรียนใหม่ลงใน Memory (ถ้ามี)**:
   - หากพบข้อผิดพลาดใหม่, พฤติกรรมแปลกของฐานข้อมูล, หรือสัจพจน์สำคัญ ให้จดเพิ่มลงใน `.brain/MEMORY.md` ทันที
